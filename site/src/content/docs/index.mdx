The same `Service` type that generated `demo` validates `deployed` documents from the outside world:

```bash
decl validate services.decl --input deployed=prod.json
```

## Install

<Tabs syncKey="channel">
  <TabItem label="npm">
    ```bash
    npm install -g decl-lang
    ```
    The reference implementation: checker, evaluator, formatter, and the `decl-lsp` language server (Node.js ≥ 20).
  </TabItem>
  <TabItem label="pip">
    ```bash
    pip install decl
    ```
    Native Python runtime for `evaluate` / `validate` plus a Python API; `check`, `fmt`, and the language server run the bundled reference.
  </TabItem>
  <TabItem label="cargo">
    ```bash
    cargo install decl-lang
    ```
    Native Rust runtime: `decl evaluate` and `decl validate` with no Node or wasm.
  </TabItem>
  <TabItem label="brew">
    ```bash
    brew install luuvish/decl/decl
    ```
    The npm package through a Homebrew tap.
  </TabItem>
</Tabs>
